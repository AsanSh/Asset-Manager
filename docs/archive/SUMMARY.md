## 🔌 API ENDPOINT

### `GET /api/construction/projects/:id/cost-analysis`

Возвращает полный анализ проекта:

```json
{
  "costs": {
    "plannedCostPerSqm": 15000,      // план за м²
    "actualCostPerSqm": 13500,       // факт за м²
    "costDeviation": -10,            // % отклонения
    "budgetProgress": 63.3           // % исполнения
  },
  "sales": {
    "soldUnits": 45,                 // продано
    "totalUnits": 80,                // всего
    "totalRevenue": 180000000,       // выручка
    "salesProgress": 56.25           // % заполнения
  },
  "profitability": {
    "profit": 85000000,              // прибыль
    "profitMargin": 89.5,            // маржа %
    "roi": 56.7                      // ROI %
  }
}
```

**Формулы:**
```
Себестоимость = Σ расходов / Площадь
Прибыль = Выручка - Расходы
Маржа = (Прибыль / Расходы) × 100%
ROI = (Прибыль / Бюджет) × 100%
```

## 🔗 ИНТЕГРАЦИЯ ШАХМАТКИ С CRM

### Workflow:

```
1. Создание юнита               2. Продажа через CRM         3. Автообновление
┌──────────────────┐           ┌──────────────────┐         ┌──────────────────┐
│ Шахматка         │           │ CRM              │         │ Статус юнита     │
│                  │   связь   │                  │  обнов  │                  │
│ Юнит: A-101      │ ────────> │ Договор #456     │ ──────> │ status = sold    │
│ status=available │           │ Клиент: Иванов   │         │ contract_id=#456 │
│ price=1.75млн    │           │ amount=1.75млн   │         │ client_id=#789   │
└──────────────────┘           └──────────────────┘         └──────────────────┘
```

### Статусы:
- 🟢 `available` → Доступен для продажи
- 🟡 `reserved` → Забронирован клиентом
- 🔵 `sold` → Продан (договор подписан)
- ⚪ `registered` → Зарегистрирован в гос. органах
