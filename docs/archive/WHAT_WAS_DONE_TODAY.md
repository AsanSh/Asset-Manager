### 2. BACKEND API ✅

#### Новый endpoint: `GET /construction/projects/:id/cost-analysis`

**Что возвращает:**
- 📊 Себестоимость (план vs факт)
- 💰 Бюджет (исполнение, остаток)
- 🏢 Продажи (кол-во, выручка, прогресс)
- 📈 Прибыльность (profit, margin, ROI)

**Файл:** `/artifacts/api-server/src/routes/construction.ts`

**Формулы:**
```javascript
actualCostPerSqm = totalSpent / totalArea
profit = totalRevenue - totalSpent
profitMargin = (profit / totalSpent) × 100%
ROI = (profit / totalBudget) × 100%
budgetProgress = (spent / budget) × 100%
salesProgress = (sold / total) × 100%
```

**Статус:** ✅ Реализовано, протестировано

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐

└──────────────┘      └──────────────┘      └──────────────┘
```

#### Статусы юнитов:
- 🟢 `available` - Доступен
- 🟡 `reserved` - Забронирован
- 🔵 `sold` - Продан
- ⚪ `registered` - Зарегистрирован

**База данных:**
```sql
-- При создании договора продажи:
UPDATE construction_units SET
  status = 'sold',
  sales_contract_id = {contract_id},
  client_id = {client_id},
  sale_price = {amount},
  sale_date = NOW()
WHERE id = {unit_id};
```

**Статус:** ✅ Схема готова, API ready

### 4. Прибыльность в реальном времени 💰
```

ROI = (Прибыль / Бюджет) × 100%
```
