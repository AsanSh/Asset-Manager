## 🎯 КЛЮЧЕВЫЕ УЛУЧШЕНИЯ

### 1. МОДУЛЬ СТРОИТЕЛЬСТВА (Construction) - ПРИОРИТЕТ 1

#### 1.1 Расширенные характеристики проектов
**Текущая проблема:** При создании проекта недостаточно детализации для расчета себестоимости

**Что добавить:**
- ✅ Площадь застройки (общая, жилая, коммерческая)
- ✅ Количество этажей
- ✅ Количество квартир/юнитов по типам
- ✅ Стоимость за м² (плановая)
- ✅ Дата начала / дата завершения (плановая и фактическая)
- ✅ Статус проекта (планирование, строительство, завершен)
- ✅ Юридическое лицо (связь с legal_entities)
- ✅ Общий бюджет проекта

**База данных:**
```sql
ALTER TABLE construction_projects ADD COLUMN:
- total_area DECIMAL(10,2) -- общая площадь
- residential_area DECIMAL(10,2) -- жилая площадь
- commercial_area DECIMAL(10,2) -- коммерческая площадь
- floors_count INTEGER -- этажей
- units_1room INTEGER -- кол-во 1-комн
- units_2room INTEGER -- кол-во 2-комн
- units_3room INTEGER -- кол-во 3+ комн
- cost_per_sqm DECIMAL(10,2) -- стоимость м²
- start_date_planned DATE
- completion_date_planned DATE
- completion_date_actual DATE
- total_budget DECIMAL(15,2)
- legal_entity_id INTEGER REFERENCES legal_entities(id)
```

#### 1.2 Улучшенная шахматка с интеграцией продаж
**Текущая проблема:** Шахматка существует, но нет связи с договорами продажи

**Что реализовать:**
- ✅ При создании договора продажи через CRM - автоматическая подвязка к юниту в шахматке
- ✅ Статусы юнита: свободен → забронирован → продан → оформлен
- ✅ Цветовая индикация статусов в шахматке
- ✅ Отображение клиента и номера договора при наведении
- ✅ Быстрый переход из шахматки в договор продажи
- ✅ Расчет выручки по проекту (проданные юниты)

**База данных:**
```sql
ALTER TABLE construction_units ADD COLUMN:
- sales_contract_id INTEGER REFERENCES crm_sales_contracts(id)
- client_id INTEGER REFERENCES crm_clients(id)
- sale_price DECIMAL(15,2)
- sale_date DATE
- registration_date DATE

CREATE INDEX idx_units_sales ON construction_units(sales_contract_id);
```

#### 1.3 Онлайн расчет себестоимости
**Формула:**
```
Себестоимость 1 м² = (Σ всех расходов по проекту) / (Общая площадь)
Прибыльность = ((Σ продаж - Σ расходов) / Σ расходов) * 100%
Средняя цена продажи = Σ продаж / Кол-во проданных юнитов
```

**Виджет на Dashboard:**
- Плановая себестоимость м²
- Фактическая себестоимость м² (по мере строительства)
- Прогноз прибыли
- % готовности проекта
- % проданных юнитов

#### 1.4 Бюджет проекта с план/факт
**Разделы бюджета:**
1. Материалы (по категориям из warehouse)
2. Работы (подрядчики)
3. Оборудование
4. Накладные расходы
5. Резерв

**Отображение:**
- План / Факт / Отклонение
- % исполнения по каждой статье
- Alerts при превышении бюджета >10%
- Прогноз бюджета на конец проекта

### 2. МОДУЛЬ CRM / PROPTECH - ПРИОРИТЕТ 2

#### 2.1 Улучшенная интеграция с Construction
**Связи:**
- Объекты на продажу (crm_sales_properties) ← привязка к construction_projects
- При создании договора продажи → выбор юнита из шахматки
- Автоматическое обновление статуса юнита при подписании договора
- График платежей по договору → связь с payments

#### 2.2 Клиентский портал (PropTech)
**Функции для клиентов:**
- Просмотр своего юнита в 3D шахматке
- График платежей и оплаченные суммы
- Фотоотчеты со стройки (по этажам/периодам)
- Документы (договор, акты, чеки)
- Чат с менеджером
- Уведомления о новых платежах

**База данных:**
```sql
CREATE TABLE construction_progress_photos (
  id SERIAL PRIMARY KEY,
  project_id INTEGER REFERENCES construction_projects(id),
  floor_number INTEGER,
  photo_url TEXT,
  description TEXT,
  taken_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE client_notifications (
  id SERIAL PRIMARY KEY,
  client_id INTEGER REFERENCES crm_clients(id),
  type VARCHAR(50), -- payment_due, progress_update, document_ready
  message TEXT,
  read BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### 2.3 Маркетинговый портал для продаж
**Публичная страница проекта:**
- Красивая презентация проекта (карусель фото)
- Интерактивная шахматка (показать доступные юниты)
- Калькулятор ипотеки
- Форма заявки (создание лида)
- Виртуальный тур (если есть)
- Генплан комплекса
- Инфраструктура района

### 3. СИСТЕМНАЯ АРХИТЕКТУРА - ПРИОРИТЕТ 3

#### 3.1 Многоуровневая навигация (как в Adesk)
```
Строительство
├─ Основное
│  ├─ Dashboard
│  ├─ Проекты
│  ├─ Шахматка
│  └─ Операции
├─ Аналитика ⚡
│  ├─ Себестоимость
│  ├─ P&L по проектам
│  ├─ Бюджет план/факт
│  └─ Отчет по продажам
├─ Планирование 📅
│  ├─ Бюджеты проектов
│  ├─ График работ
│  └─ Закупки
└─ Настройки ⚙️
   ├─ Категории работ
   ├─ Шаблоны бюджетов
   └─ Права доступа
```

#### 3.2 Уведомления и Alerts
**Типы уведомлений:**
- 🔴 Превышение бюджета >10%
- 🟡 Просрочка по задаче >3 дня
- 🟢 Новый договор продажи
- 🔵 Поступление платежа от клиента
- ⚪ Низкий остаток материала на складе

#### 3.3 Права доступа (RBAC)
**Роли:**
- Owner - полный доступ
- Admin - все кроме настроек компании
- Construction Manager - строительство + закуп
- Sales Manager - CRM + шахматка (только просмотр)
- Accountant - финансы + отчеты
- Warehouse Manager - склад
- Client - только портал клиента

#### 3.4 Workflow согласований
**Цепочка:**
1. Менеджер создает заявку на закуп материалов
2. Прораб согласовывает спецификацию
3. Бухгалтер проверяет бюджет
4. Директор утверждает платеж >100,000
5. Кладовщик принимает товар
6. Система автоматически списывает из бюджета
